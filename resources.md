# Resources

These references support the work around the coding agent. They are deliberately limited to authoritative documentation and practical starting points.

## Coding agents

- [OpenAI Codex documentation](https://developers.openai.com/codex/) — product documentation and working patterns for one coding-agent environment.
- [GitHub documentation on coding agents](https://docs.github.com/en/copilot/concepts/agents/about-third-party-coding-agents) — how coding agents can work on repository tasks through GitHub.

Use the platform that fits the project. The brief, source of truth, review and release responsibilities in this repository remain the same.

## Git and GitHub basics

- [Pro Git: Git Basics](https://git-scm.com/book/en/v2/Git-Basics-Getting-a-Git-Repository) — repositories, tracking files, commits and remotes.
- [GitHub: Writing and storing your code](https://docs.github.com/en/get-started/start-your-journey/writing-and-storing-your-code) — a guided introduction to repositories and changes.

## Hosting and previews

- [Netlify Deploy Previews](https://docs.netlify.com/deploy/deploy-types/deploy-previews/) — reviewing a real build without publishing it to production.
- [Vercel deployment environments](https://vercel.com/docs/deployments/environments) — the distinction between local, preview and production environments.

## Accessibility

- [W3C Web Accessibility Initiative tutorials](https://www.w3.org/WAI/tutorials/) — task-based guidance for accessible images, forms, tables and page structure.
- [How to Meet WCAG](https://www.w3.org/WAI/WCAG22/quickref/) — a filterable reference for WCAG 2.2 requirements and techniques.

## Responsive design

- [MDN: Responsive web design](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design) — the principles behind layouts that work across screen sizes.

## Performance

- [web.dev: Learn Performance](https://web.dev/learn/performance) — a structured introduction to measuring and improving web performance.

## Analytics and consent

- [Google: Set up consent mode on websites](https://developers.google.com/tag-platform/security/guides/consent) — implementation guidance when a site uses Google tags and an appropriate consent solution.
- [ICO: Storage and access technologies guidance](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guidance-on-the-use-of-storage-and-access-technologies/) — current UK regulatory guidance covering cookies and related technologies.

These are implementation and regulatory references, not a substitute for advice appropriate to the site, its users and its jurisdictions.

## SEO

- [Google Search Central: SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) — people-first basics for helping search engines understand a site.

## Licensing and copyright

- [Creative Commons licences](https://creativecommons.org/cc-licenses/) — what the standard CC licences permit and require.
- [Choose a License](https://choosealicense.com/) — a practical introduction to common open-source software licences.

Record the provenance and permission for each asset. A public URL is not evidence that an image, font, quotation or file is free to reuse.
