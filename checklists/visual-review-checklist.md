# Visual Review Checklist

Technical correctness and human visual judgement are different checks. A page can pass every automated test and still put the wrong thing first, feel unbalanced or fail to earn attention.

Review the real page at these widths where practical:

- 1440
- 1024
- 768
- 430
- 390
- 360

Use 1920, 1280 and 320 as edge cases when the audience or layout makes them useful.

## First screen

- [ ] The first-screen hierarchy matches the page job.
- [ ] The main claim is clear without hunting.
- [ ] The evidence appears early enough to support the claim.
- [ ] The primary action is visible and proportionate.
- [ ] A consent banner does not dominate the page or hide the point of it.

## Composition

- [ ] Image crops preserve the intended subject at every important width.
- [ ] Text and images feel balanced rather than mechanically equal.
- [ ] Typography has a clear hierarchy and comfortable line lengths.
- [ ] Spacing separates ideas without creating empty stretches.
- [ ] Logos are legible but not louder than the content they support.
- [ ] Repeated components feel related without making every page identical.

## Mobile

- [ ] The first screen still contains the most important information.
- [ ] Stacking order makes sense.
- [ ] Buttons and controls are easy to reach and read.
- [ ] Nothing important is pushed down by decorative or low-priority content.
- [ ] No horizontal scrolling, clipping or accidental overlap appears.

## Human judgement

- [ ] Nothing feels forced into the page merely for consistency.
- [ ] Nothing looks present only because similar sites usually have it.
- [ ] The page feels credible for the intended audience.
- [ ] Removing any element would not improve the page; if it would, test the removal.
- [ ] Someone has looked at the page as a visitor, not only as its builder.
