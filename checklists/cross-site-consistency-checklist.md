# Cross-Site Consistency Checklist

Read across the site, not down one page at a time. Many inconsistencies exist only in the comparison.

Classify every difference:

- **Wrong:** two versions cannot both be true. Fix against the approved source.
- **Drifted:** an approved rule exists and a page has moved away from it. Restore the rule.
- **Deliberate:** the pages do different jobs and the difference helps. Document it instead of normalising it.

## Final check

- [ ] Wrong differences were corrected against an approved source.
- [ ] Drifted differences were returned to the documented rule.
- [ ] Deliberate differences have a written reason in the brief, source of truth or decision log.
- [ ] No difference was removed merely to make every page uniform.
