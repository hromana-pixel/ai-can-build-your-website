# Decision Log

Record decisions that an agent could otherwise reopen, misread or reverse. Keep the active instruction set free of contradictions.

## How to maintain this log

- Give each decision a clear scope. A homepage decision does not automatically apply to every page.
- Mark deliberate differences as deliberate and explain the reason.
- When a decision changes, mark the old row `Superseded` and point it to the replacement.
- Remove superseded wording from active briefs and agent instructions, or label it so clearly that it cannot be mistaken for current direction.
- Do not give a coding agent two active decisions that disagree.
